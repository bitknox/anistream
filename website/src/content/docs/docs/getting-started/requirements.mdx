A prebuilt install needs only mpv and ffmpeg. The `.deb` pulls both in. Elsewhere, install them
with `brew install mpv ffmpeg`, `winget install shinchiro.mpv Gyan.FFmpeg`, or your distro's
packages.

- **mpv** 0.39 or newer does all playback, over JSON IPC. anistream brings its own controls,
  thumbnails and shaders, so a stock mpv is enough. Older builds play, but without the in-player
  menus and the one-window binge.
- **ffmpeg** is used for remuxing and subtitle handling on downloads.

## Building from source

Building also needs Rust, cmake and a C toolchain, and NASM on Windows:

<Tabs syncKey="platform">
<TabItem label="macOS">

```sh
brew install mpv ffmpeg cmake      # cmake is for wreq's BoringSSL
rustup toolchain install 1.97.1    # pinned by rust-toolchain.toml
```

</TabItem>
<TabItem label="Linux">

```sh
sudo apt install mpv ffmpeg cmake build-essential pkg-config   # Debian / Ubuntu
sudo dnf install mpv ffmpeg cmake gcc-c++                      # Fedora
sudo pacman -S mpv ffmpeg cmake base-devel                     # Arch
```

</TabItem>
<TabItem label="Windows">

```powershell
winget install --id Rustlang.Rustup
winget install --id Kitware.CMake
winget install --id NASM.NASM
winget install --id Gyan.FFmpeg
winget install --id shinchiro.mpv
winget install --id Microsoft.VisualStudio.2022.BuildTools
```

NASM and the MSVC build tools are extra on Windows because the torrent stack compiles C and
assembles its own crypto primitives. See
[installation](/docs/getting-started/installation/) for the full walkthrough.

</TabItem>
</Tabs>

- **cmake** builds BoringSSL for the browser-fingerprint HTTP stack.
- **Rust 1.97.1** is pinned by `rust-toolchain.toml`, so `rustup` picks it up automatically inside
  the repo.

Optional:

- `rustup target add wasm32-wasip2`, only if you want to build
  [plugins](/docs/plugins/authoring/).

## Terminal

Use a terminal with a real graphics protocol if you can: **Ghostty, Kitty, iTerm2, WezTerm**. Cover
art renders as actual images over the Kitty, Sixel or iTerm2 protocols. Elsewhere it falls back to
Unicode halfblocks. On Windows, WezTerm is one of them.

```sh
anistream --doctor
```

reports what your terminal supports, which mpv you have and which config it reads, and, once the
torrent source is enabled, the state of the VPN guard and your VPN's kill switch.
