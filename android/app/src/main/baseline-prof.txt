# The app's own baseline profile; the libraries' own profiles, Compose's among them, come with them.
#
# The screens, the design system, the player and the store are here whole: every method of the
# :ui, :design, :player and :store modules, as wildcards, the way the Compose libraries write
# theirs. So the start, every destination, a title page and its season change, Settings and the
# player opening run compiled from the first time they are used rather than interpreted, however
# their code moves. So do the parts of Compose the first menu or sheet runs, which the libraries'
# own profiles leave out. The rest is what a cold start, Continue, the five destinations and a title page
# ran in the engine's bindings and the app, recorded from ART's profile of a debug build (cmd
# package dump-profiles); D8's synthetic lambdas are left out, since their names change from build
# to build.
