# Support

- Read the docs at [anistream.tv/docs](https://anistream.tv/docs/). Writing a plugin is covered
  in [docs/plugins.md](docs/plugins.md), and running a plugin store in
  [docs/plugin-stores.md](docs/plugin-stores.md).
- For a question or an idea, start a [discussion](https://github.com/bitknox/anistream/discussions).
- For a bug or a feature request, [open an issue](https://github.com/bitknox/anistream/issues/new/choose).
  Say which app and version you use, and what you did. Don't link to sources or name sites that
  carry content; anistream hosts no content. We can't help with them.
- For a vulnerability, don't open an issue. Follow [SECURITY.md](SECURITY.md).
- To change something yourself, see [CONTRIBUTING.md](CONTRIBUTING.md).
